# 專案文件

此目錄收錄使用者、開發者、發布與專案規劃文件。快速介紹請參閱根目錄的 [README](../README.md)。

## 文件索引

### 使用者文件

- [專案概覽](PROJECT_OVERVIEW.md)：定位、功能、技術摘要與目前狀態。
- [使用指南](USER_GUIDE.md)：安裝、編輯、播放與設定操作。
- [隱私與資料保存](PRIVACY.md)：本機資料、系統備份與清除方式。

### 開發者文件

- [系統設計](SYSTEM_DESIGN.md)：架構、資料流、持久化、渲染與技術風險。
- [建置與發布](BUILD_RELEASE.md)：環境、指令、測試及 Pre-release 規則。
- [MIT License 繁中摘要](LICENSE.zh-TW.md)：授權重點說明；正式條款以英文 [LICENSE](../LICENSE) 為準。

### 規劃與紀錄

- [優化建議](OPTIMIZATION_SUGGESTIONS.md)：介面、功能、資料安全及工程品質評估。
- [待辦事項](TODO.md)：依優先級與版本階段整理的工作清單。
- [版本紀錄](../CHANGELOG.md)：使用者可見的版本變更。
- [1.0.2 Pre-release 說明](RELEASE_NOTES_1.0.2-prerelease.md)：目前公開測試版本內容與安裝提醒。

## 維護原則

- 新需求先記錄於 `TODO.md`，完成後同步更新狀態。
- 影響產品方向或優先級時，同步更新 `OPTIMIZATION_SUGGESTIONS.md`。
- 發布版本時更新根目錄的 `CHANGELOG.md`。

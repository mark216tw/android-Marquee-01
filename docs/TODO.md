# 待辦事項

本清單依據 [優化建議](OPTIMIZATION_SUGGESTIONS.md) 整理。工作順序以資料安全、核心操作、無障礙與測試為優先，再進行管理功能及正式發佈準備。

## 狀態規則

- `[ ]`：尚未完成。
- `[x]`：已完成並通過驗收。
- 開始工作時可在項目後加入負責人、Issue 或 PR 連結。
- 功能完成後應同步加入或更新測試；發布時再將使用者可見變更寫入 `CHANGELOG.md`。

## P0：近期修正版

### 編輯流程

- [x] `P0-01` 修正新增預設未修改仍顯示「放棄變更」的問題。
  驗收：剛進入新增頁直接取消不顯示確認；修改任一欄位後取消才顯示確認。
- [x] `P0-02` 為新增與編輯流程保存初始草稿快照。
  驗收：變更判斷同時適用於新增及編輯預設。
- [ ] `P0-03` 使用 `SavedStateHandle` 保存未完成草稿及目前編輯狀態。
  驗收：Activity 重建或程序恢復後，所有編輯欄位維持原值。
- [ ] `P0-04` 恢復未完成內容時顯示清楚提示。
  驗收：使用者能辨識畫面內容是由草稿恢復，而非已正式儲存。

### 資料安全

- [ ] `P0-05` 為預設資料加入 `schemaVersion`。
  驗收：新資料包含版本，舊資料仍可正常載入。
- [ ] `P0-06` 將預設 JSON 改為逐筆解析，隔離單筆損壞資料。
  驗收：一筆資料損壞時，其他有效預設仍正常顯示。
- [ ] `P0-07` 覆寫資料前保留最近一份可讀備份。
  驗收：主要資料損壞時可由備份恢復。
- [ ] `P0-08` 資料解析失敗時顯示錯誤及復原選項，不再靜默載入範例。
  驗收：錯誤不會造成原始資料被無提示覆蓋。

### 播放器

- [x] `P0-09` 為播放器增加可重新叫出的播放／暫停及離開控制列。
  驗收：使用者不依賴系統返回手勢即可暫停及離開。
- [x] `P0-10` 修正暫停面板及提示在明亮模式下的文字對比。
  驗收：六組介面主題的明亮與深色模式皆清楚可讀。
- [x] `P0-11` 暫停播放器時同步停止動態彩虹動畫。
  驗收：暫停後文字位移與漸層皆停止更新。
- [ ] `P0-12` 為播放器操作加入 `role`、`onClickLabel` 與狀態描述。
  驗收：TalkBack 能讀出目前播放狀態及可執行操作。
- [ ] `P0-13` 為暫停狀態加入 live region 或等效公告。
  驗收：狀態改變時 TalkBack 會主動提供回饋。
- [ ] `P0-14` 清除重複跑馬燈副本的語意，只保留一份可存取文字。
  驗收：TalkBack 不會重複朗讀同一句內容。

### 測試基線

- [x] `P0-15` 加入單元測試及 Compose UI 測試所需依賴與目錄。
- [ ] `P0-16` 測試 `PresetStore` 的正常、損壞、舊版及未知 enum 資料。
- [ ] `P0-17` 測試新增、編輯、儲存、複製、刪除及取消流程。
- [ ] `P0-18` 為未修改新增草稿的取消行為加入回歸測試。
- [ ] `P0-19` 測試 Activity 重建後的草稿恢復。
- [ ] `P0-20` 測試播放器播放、暫停、返回及無障礙語意。

## 完成定義

每個待辦事項完成前應確認：

- 行為符合項目中的驗收條件。
- 新增或更新必要的單元測試與 UI 測試。
- `testDebugUnitTest`、`lintDebug` 及 `assembleDebug` 通過。
- 已檢查明亮／深色、窄螢幕、大字體及必要的 TalkBack 行為。
- 使用者可見變更已更新 README 或 `CHANGELOG.md`。
- 實作結果若改變原規劃，已同步更新優化建議與本清單。

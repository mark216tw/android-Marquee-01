# 使用指南

## 安裝

從 GitHub Releases 下載標示為 Pre-release 的 APK。Android 可能要求允許瀏覽器或檔案管理器安裝未知來源應用程式。

目前 APK 使用 Debug 金鑰簽署，只適合測試。未來正式版改用正式簽章後，可能需要先解除安裝測試版本。

## 首頁

- 點擊頂部的 `+` 建立跑馬燈。
- 點擊預設卡片的「播放」進入全螢幕播放器。
- 點擊「編輯」修改預設。
- 點擊更多選單可複製、上移、下移或刪除預設。
- 長按拖曳手柄可直接調整排序，放開後自動保存。
- 點擊齒輪圖示進入介面設定。

刪除前會顯示確認對話框，目前不支援刪除後復原。

## 新增與編輯

### 內容

輸入預設名稱與顯示文字。名稱及文字不可為空。播放時換行會轉換成空格，以單行方式顯示。

### 播放方向

- 跟隨系統：不鎖定裝置方向。
- 鎖定橫屏：播放時維持橫向。
- 鎖定直屏：播放時維持直向。
- 開始時為靜止狀態：進入播放器時先暫停並顯示「繼續」按鈕。

### 主題色彩

可以選擇內建配色、使用 HSV 色彩選擇器，或透過進階 Hex 欄位輸入不透明的 `#RRGGBB` 色碼。純色模式會顯示文字與背景的 WCAG 對比結果；低對比只會警告，不會禁止儲存。

### 文字效果

- 無效果：使用原始文字樣式。
- 描邊：在文字外圍加入自動選擇的黑色或白色外框。
- 呼吸亮度：播放時讓文字亮度平滑明暗循環；暫停時停在當下亮度。
- 霓虹：在文字後方加入光暈，深色背景下效果較明顯。

### 文字樣式

可調整字體大小、字距與字重。開啟鏡像文字模式後，字形會水平翻轉，實際滾動方向也會反轉，適合鏡面或提詞器使用情境。

### 滾動

可調整速度、循環間距，以及向左或向右滾動。鏡像模式開啟時，畫面上的實際方向會與此設定相反。

完成後點擊「儲存」。若修改後取消或返回，App 會要求確認是否放棄變更。

## 播放器

- 播放中控制列會在約三秒後自動隱藏。
- 點擊畫面可顯示或隱藏控制列。
- 點擊「暫停」停止文字位移、呼吸亮度與動態彩虹。
- 暫停後控制列會保持顯示，點擊「繼續」恢復播放。
- 點擊「返回」離開播放器並恢復一般系統介面。

## 介面設定

- 深色模式：切換 App 的淺色或深色介面。
- 播放畫面保持常亮：開啟時，播放器不會因系統逾時自動關閉螢幕。
- 介面主題：選擇六組快捷色或拖曳 Hue 滑桿自訂色相。

設定會立即保存，重新啟動 App 後仍會保留。

## 已知限制

- 尚無搜尋、釘選、匯入、匯出、分享及雲端同步。
- 未完成的編輯草稿在 App 程序被系統終止後可能遺失。
- 預設資料損壞時尚無 App 內復原流程。
- 尚未提供正式簽章的正式上線版本。

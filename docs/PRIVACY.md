# 隱私與資料保存

## 資料收集

本 App 不要求帳號，Manifest 未宣告網路、相機、麥克風、定位、聯絡人或廣泛檔案存取權限。專案也未整合廣告、分析或第三方追蹤 SDK。

## 儲存內容

App 會在應用程式私有儲存空間保存：

- 跑馬燈預設名稱與顯示文字。
- 字型、色彩、文字效果、速度、方向及播放設定。
- 深色模式、介面 Hue 與保持螢幕常亮偏好。

資料使用 SharedPreferences 與 JSON 保存，未額外加密，也不會由 App 主動上傳至開發者或其他服務。

## Android 系統備份

目前 Manifest 啟用 Android 系統備份，且尚未設定專用備份規則。因此，資料可能由 Android Auto Backup 或裝置轉移服務備份及還原，實際行為取決於裝置、Android 版本與使用者的系統設定。

這表示資料主要存於 App 私有本機空間，但不能保證永遠只存在原裝置。

## 清除資料

- 可在 App 內刪除個別跑馬燈預設。
- 可透過 Android 系統設定清除 App 儲存空間。
- 解除安裝會移除裝置上的 App 私有資料，但系統備份副本可能在重新安裝或換機時還原。

目前沒有 App 內匯出、雲端同步或備份復原功能。

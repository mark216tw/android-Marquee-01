# 1.0.2 Pre-release

此版本為 **Pre-release 公開測試版本**，不是正式上線版本。APK 已啟用 R8 與資源壓縮，但使用 Android Debug 金鑰簽署，僅供功能試用與測試。

## 主要內容

- APP 名稱與首頁標題更新為「LED跑馬燈」。
- APP 圖示移除 LED 文字下方的笑臉，調整 LED 大小並置中，與邊框保持間距。
- 新增描邊、呼吸亮度與霓虹文字效果。
- 新增鏡像文字模式，並同步反轉跑馬燈移動方向。
- 新增「開始時為靜止狀態」。
- 新增播放畫面保持常亮設定。
- 簡化播放器控制列，移除播放狀態文字。
- 調整編輯器設定順序與底部安全區域。
- 首頁新增操作改為頂部加號，列表避開系統導覽列。
- 補充繁體中文專案、使用、系統設計、建置發布、隱私與授權文件。

## 安裝提醒

- 最低支援 Android 8.0（API 26）。
- 手動安裝時，Android 可能要求允許安裝未知來源應用程式。
- 未來正式版改用正式 Release 金鑰後，可能無法直接覆蓋此測試版本。
- 建議先備份重要文字內容；目前尚無 App 內匯出或復原功能。

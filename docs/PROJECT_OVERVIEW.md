# 專案概覽

## 專案定位

LED跑馬燈是一款以 Android 裝置顯示全螢幕跑馬燈的開源應用程式。使用者可以建立多組訊息、調整文字外觀與滾動方式，並將設定保存在裝置上，以便快速重複播放。

目前版本為 `1.0.2-prerelease`，屬於公開測試版本，不是正式上線版本。Prerelease APK 經 R8 與資源壓縮處理，但使用 Android Debug 金鑰簽署，僅適合測試與功能預覽。

## 主要功能

- 建立、編輯、複製、刪除及排序多組跑馬燈預設。
- 即時預覽文字、背景、速度、方向與顯示效果。
- 支援純色、靜態彩虹與動態彩虹配色。
- 支援描邊、呼吸亮度及霓虹文字效果。
- 支援字級、字距、字重及鏡像文字；鏡像會同步反轉滾動方向。
- 支援向左或向右滾動、循環間距及開始時保持靜止。
- 支援跟隨系統方向、鎖定橫屏或鎖定直屏。
- 提供播放、暫停、返回及可重新叫出的全螢幕控制列。
- 可選擇播放時保持螢幕常亮。
- 支援淺色／深色介面與自訂 Hue 主題色。

## 技術摘要

- Kotlin 2.2.20
- Jetpack Compose 與 Material 3
- 單一 Activity 與 AndroidViewModel
- SharedPreferences 與 JSON 本機持久化
- Android 8.0（API 26）以上
- compileSdk／targetSdk 36
- JDK 17、Gradle 8.14.3、Android Gradle Plugin 8.11.1
